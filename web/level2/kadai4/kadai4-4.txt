・SVG（Scalable Vector Graphics）
ベクター画像を XML 形式で記述する技術。拡大縮小しても劣化しないため、アイコンやグラフ、アニメーションなどに用いられる。
・MathML（Mathematical Markup Language）
数式を Web 上に正確に記述するためのマークアップ言語。学術論文や教育コンテンツなどで使用される。
・WAI-ARIA（Accessible Rich Internet Applications）
障害のあるユーザーが Web を利用しやすくするためのアクセシビリティ仕様。スクリーンリーダーでの読み上げ補助などに活用される。
・WebRTC（Web Real-Time Communication）
ブラウザ同士で音声・映像・データ通信ができる技術。ビデオ通話サービスなどで利用されている。
・WOFF（Web Open Font Format）
Web フォントを配信するためのフォント形式。デザイン性の高い Web サイトを実現するために使われる。


Web 制作者として Web 標準に準拠するべき理由
・どのブラウザでも正しく表示されるため
Web 標準に従って制作すれば、Chrome・Safari・Firefox など環境が違っても同じようにページが動作し、利用者にとって使いやすくなる。
・長期的な保守がしやすいため
標準に沿ったコードは読みやすく、他の制作者が後から引き継ぐ際にも理解しやすい。その結果、トラブルが発生しにくくなる。
・アクセシビリティやセキュリティの向上につながるため
Web 標準は「多様なユーザーが安全に使える」ことを前提に作られており、その基準に合わせることで安心して使える Web を提供できる。
・検索エンジンに正しく評価されるため（SEO）
標準に沿った構造化された HTML は検索エンジンに理解されやすく、結果として検索順位の向上にも寄与する。
